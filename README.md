# BouRide - Bougainville Rideshare

   **For 2G phones. For PMV drivers. For AROB.**

   BouRide connects passengers and PMV drivers in Bougainville using USSD *777#. No smartphone or internet needed.

   ## How It Works
   1. Passenger dials *777# on Digicel/Bmobile
   2. Chooses route: Arawa > Buka, Buka > Buin, etc.
   3. System matches with registered PMV driver
   4. Passenger pays driver cash. K25 standard fare Arawa-Buka.

   ## Why BouRide
   80% of Bougainville uses 2G button phones. PMVs are the main transport. BouRide makes PMVs safer, faster, and fair.
