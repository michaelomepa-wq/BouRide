# BouRide - Bougainville Rideshare

**For 4G phones and 2G button phones. For PMVs and taxis. For AROB.**

BouRide connects passengers with PMV drivers and taxi operators in Bougainville using USSD *777#. Works on any phone — smartphone or button phone. No internet needed.

## How It Works
1. Passenger dials *777# on Digicel/Bmobile
2. Chooses: Book PMV Ride OR Book Taxi
3. For PMV: Selects fixed route like Arawa > Buka. For Taxi: Enters pickup/drop-off
4. System matches with registered PMV driver or taxi operator
5. Passenger pays driver cash. K25 standard PMV fare Arawa-Buka. Taxi fares negotiated with driver.

## Why BouRide
Bougainville runs on PMVs and taxis. Many people use 4G smartphones but 2G button phones are still common. BouRide works for both — dial *777# and book.
